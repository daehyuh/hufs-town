# 계정 탈퇴와 개인정보 처리

2026-09-23. T24.3의 첫 수직 경로를 구현했다. 탈퇴 전 소유 공간을 보여 주고, 사용자가 `탈퇴`를 직접 입력한 뒤 계정·개인 콘텐츠·세션 정리를 요청한다. 실제 삭제 실행은 API 트랜잭션에 묶여 있다.

## 동작 규칙

- `GET /api/v1/auth/account/deletion-impact`는 현재 계정이 소유한 공간 ID와 이름을 반환한다. 소유 공간이 하나라도 남으면 `DELETE /api/v1/auth/account`는 409로 거절되며, 사용자는 멤버 관리에서 소유권을 이전해야 한다.
- 탈퇴 요청은 정확한 확인 문자열 `탈퇴`와 유효한 세션/CSRF를 요구한다. DB 트랜잭션 안에서 계정과 공간을 잠근 뒤, 인덱싱된 Redis 사용자 세션을 먼저 폐기한다. Redis 실패 시 DB 트랜잭션이 롤백된다. 성공하면 현재 세션도 무효화한다.
- SSO 연결, 프로필 설명/링크, 아바타 설정, 푸시 구독, 즐겨찾기·차단·멤버십·공간 초대·합류 요청을 제거한다. 계정 행은 `DELETED` 상태와 비식별 표시 이름만 남기고, 동일 SSO로 로그인해도 삭제 전 UUID 계정이나 콘텐츠가 복원되지 않도록 SSO identity 연결을 제거한다. 탈퇴 계정 대상의 채팅·월드·미디어 제한은 제거하고, 게스트 제한·DM 변경·전달 outbox에서 탈퇴 계정이 관리/행위자로 남은 참조도 제거한다.
- 작성한 공간 채팅/DM, 게시판 글, 행사 질문·참석·투표, 일정 참석 기록은 지운다. 투표 집계도 함께 감소한다. DM 그룹 소유권은 가장 먼저 참가한 활성 멤버에게 넘기고, 그룹 생성 키에 포함된 탈퇴 계정 UUID도 대화별 비식별 값으로 바꾼다. 활성 승계자가 없거나 멤버가 2명 미만으로 남는 대화는 삭제한다.
- 다른 멤버가 사용하는 승인된 업로드 에셋과 예약 일정은 유지하되 작성자 연결을 비우고 에셋 파일명은 일반 값으로 바꾼다. 미승인 에셋은 `REJECTED`로 전환하고 검수자 참조를 제거한 뒤 저장 이미지/미리보기 파일을 즉시 삭제한다. 삭제 실패나 비정상 종료로 남은 `REJECTED` 파일과 참조가 끊긴 24시간 이상 된 업로드 파일은 매일 정리 작업이 재시도한다. 맵 수정 기록과 회의실 메모/수정 이력의 작성자 ID·이름은 비식별 처리한다. 공유 회의실 메모 본문은 현재 기능의 회의 종료 후 30일 보존 규칙을 따른다. 진행 중인 행사는 유지하고 탈퇴자는 진행자에서 제거한다.
- 신고·검토 기록은 조사 목적으로 현재 정해진 최대 180일 보존 기간을 따른다. 사용자 ID와 이름은 익명화한다. 관리자 조치 감사의 actor/target ID와 자유 메모는 제거하고 감사 행 자체는 현재 정책의 최대 365일 보존 기간을 따른다.

## 검증

`SsoIntegrationTest.accountDeletionBlocksOwnedSpacesErasesPersonalDataAndRevokesEverySession`은 API와 패키징한 별도 월드 프로세스, 임시 MariaDB·Redis를 사용한다. 이 시나리오에서 두 브라우저 세션과 월드 소켓의 폐기, 소유 공간 존재 시 거절, 소유권 이전 뒤 재시도, 개인 글·투표 제거와 집계 갱신, 그룹 대화 소유권 승계, 보존 자료 익명화, 같은 SSO subject의 새 서비스 계정 생성을 확인한다. 확장 검증은 공간 초대·합류 요청, DM 변경/전달 행위자 참조, 게스트 제재 관리자, 회의실 메모 작성자 스냅샷 제거와 미승인 에셋 표시 이름 익명화를 포함한다. Flyway V35도 MariaDB 11.4에서 적용했다. V36은 탈퇴 계정의 미승인 에셋을 거절 상태로 전환한다.

2026-09-24 재검증: Docker Testcontainers 환경에서 전체 `SsoIntegrationTest` 18/18 통과했다. 이전 실행에서 월드의 `AUTH_REQUIRED` 이벤트를 놓친 단일 실패는 분리 실행과 전체 재실행에서 재현되지 않았다. 다음에 실패하면 수신한 월드 이벤트를 테스트 오류에 포함해 원인을 구분하도록 진단을 보강했다.

2026-09-25 재검증: Docker 기반 필터 실행으로 `accountDeletionBlocksOwnedSpacesErasesPersonalDataAndRevokesEverySession`가 다시 통과했다. 소유 공간 차단과 이전 후 재시도, 전 브라우저 세션/월드 소켓 폐기, 개인 데이터 처리와 같은 SSO subject의 새 계정 분리를 확인했다.

2026-09-23 로컬 실행 확인: API·월드·웹을 공식 개발 실행기로 재기동하고 API·월드 health UP, 웹 HTTP 200을 확인했다. API 시작 때 로컬 Docker MariaDB에 Flyway V35가 성공적으로 적용됐다.

자동 통합 검사에서 실제 GDG HUFS IdP HTTP 전송은 모의 처리한다. 실제 IdP 왕복에서 새 계정이 만들어지는 사용자 흐름과 공간 이전 UI를 사용하는 다중 계정 확인은 남아 있다. 공유 회의실 메모 수정 본문을 탈퇴 시 즉시 삭제할지, 공동 기록으로 남겨 30일 보존할지도 서비스의 개인정보 보존 정책으로 확정해야 한다. 미승인 업로드 파일은 DB에서 `REJECTED` 처리되고 저장 파일의 즉시 삭제와 주기적 재시도를 적용한다. 삭제 대상 파일이 파일 시스템에서 실제 제거되는 Testcontainers 회귀 검사는 아래 2026-09-29 기록을 따른다. 이 사용자 정책 및 실제 계정 검수가 남아 T24.3은 `VERIFYING`이다.

- `GET /api/v1/auth/account/deletion-impact`
