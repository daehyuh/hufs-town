# 회의실 공유 메모

로그인한 참가자는 같은 비공개 회의실에서 공유 메모를 열고 함께 수정할 수 있다. 메모는 공간·맵·비공개 구역에 연결되며, 서버가 참가자의 현재 좌표와 게시된 맵을 확인해 구역 권한을 판정한다. 공개 구역, 다른 회의실, 비로그인 연결은 메모를 읽거나 바꿀 수 없다.

## 동시 편집과 저장

- 본문은 최대 4,000 유니코드 코드 포인트다. 프론트는 글자 수, 마지막 수정자, 수정 시각, 최근 변경 이력 20개를 보여준다.
- MariaDB 문서 행 잠금과 `baseRevision` 비교로 동시에 저장된 수정 하나만 해당 revision을 반영한다. 오래된 revision은 `ROOM_NOTE_CONFLICT`와 최신 상태를 돌려보내며, 작성자가 내용을 확인한 뒤 다시 저장할 수 있다.
- 요청 ID와 본문 해시를 저장해 같은 요청의 재시도는 한 번만 반영한다. Redis 알림과 MariaDB outbox polling으로 다른 World 노드에 변경을 전달하며, 수신 노드가 바쁘면 outbox cursor를 유지하고 재시도한다.
- 회의 중에는 노드별 presence heartbeat를 5초마다 기록한다. 정상 퇴장 때 다른 노드 참가자가 남아 있으면 메모를 종료하지 않는다. 노드가 비정상 종료되면 15초 heartbeat 만료와 5초 주기의 정리 작업으로 퇴장을 회복한다.
- 마지막 노드가 방을 비운 시각부터 30일 동안 본문과 revision을 보존한 뒤 삭제한다. 회의가 다시 열리면 만료 전 메모의 종료 시각과 만료 예약을 해제한다. 이미 보존 기간이 지난 문서는 새 회의에서 제거된다.

## 화면과 검증

프론트에는 비공개 회의실 전용 접근 버튼과 접근 가능한 공유 메모 대화상자가 있다. 로딩·저장·권한 오류·저장 충돌을 구분하고, 다른 구역으로 이동하거나 연결이 끊기면 화면의 메모 상태를 초기화한다. 편집 중인 초안은 충돌 상태에서 보존하며, 최신 내용 확인과 명시적 재저장을 제공한다.

검증은 MariaDB 11.4·Redis Testcontainers에서 V51 적용, 멱등 요청, 동시 수정, 충돌, 회의 종료·재입장·보존 만료, 여러 World 노드의 presence 판정, outbox 재시도를 확인한다. World 통합 검사는 로그인하지 않은 연결과 공개 구역의 메모 접근이 거절되고 다른 참가자에게 메모 내용이 전달되지 않는지 확인한다. 프론트 검사는 4,000자 제한, 상태 초기화와 저장 충돌 UI를 다룬다.
