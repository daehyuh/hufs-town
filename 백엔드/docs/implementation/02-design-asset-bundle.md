# GDG HUFS 스타터 맵과 에셋 번들

`C:\Project\hufstown\디자인에셋` 원본은 `scripts/prepare-assets.mjs`가 해시·크기·종류·출처·배포 권리 상태와 함께 전체 카탈로그에 기록한다. 전체 6,391개 중 현재 런타임 후보는 505개(7.9%)다. 실제 웹 번들에는 이 중 기본 프로필, GDG 브랜드, 화면에 쓰는 맵 오브젝트만 복사한다. 원본 폴더 전체는 프론트엔드 정적 파일로 복사하지 않는다.

런타임 그룹은 생성된 `프론트/src/generated/assetGroups.ts`와 `프론트/public/assets/catalog.json`에 기록한다.

- `brand`: GDG 마크·가로형 로고와 HUFS 캠퍼스 표지 일러스트.
- `avatarSheets`: 아바타의 기본 16×16 프레임 스프라이트시트 9개. 프로필별 추가 조합은 기존 아바타 파츠를 필요한 시점에 읽는다.
- `campusSquare`: GDG 로고와 Pixel Art 나무·수풀·건물·안내 표지. 실제 맵 오브젝트 ID와 공간 카탈로그를 기준으로 필요한 파일만 불러온다.
- `woodlandAtlas`: 16×16 타일 단위로 정리된 원본 타일셋. 첫 맵은 전체 타일시트를 화면에 깔지 않고 선별한 개별 도트 스프라이트와 코드로 그린 잔디/보도 바닥을 사용한다.

캠퍼스 광장 템플릿은 기존의 화분 나무 위주 배치를 Pixel Art 큰 나무·작은 나무·수풀·열매 수풀·건물로 바꾸고, GDG 표식과 양쪽 안내 표지 및 정자 구역을 유지한다. 맵의 각 오브젝트가 서버 카탈로그와 실제 정적 파일 양쪽에 존재하는지 TypeScript 단위 테스트와 Java `MapLoader` 계약 테스트로 확인한다. Playwright 브라우저 테스트는 맵에 지정된 모든 이미지가 로드되고 함께 그려지는지 검증한다.

## 추가로 필요한 에셋

- 서울/글로벌 캠퍼스의 실제 건물·정문·랜드마크를 표현하는 타일 크기의 HUFS 전용 도트 스프라이트. 현재 캠퍼스 그림은 로비 표지용 일러스트다.
- 강의실·도서관·카페용 벽, 창문, 문, 바닥 타일과 픽셀 단위 가구. 일부 사무 가구와 바닥은 현재 코드로 그린 임시 도트 표현이다.
- 달리기·앉기·찌르기·표정에 맞춘 아바타 프레임과 소품. 현재 이동은 기본 걷기 프레임을 재사용하며 감정/상호작용은 오버레이를 사용한다.
- 원본 Pixel Art 및 GDG 파일의 배포 권리 근거. 현재 manifest는 출처를 기록하지만 `distributionRights`를 `unverified`로 표시한다.

기본 오브젝트 카탈로그는 `scripts/create-office-assets.mjs`, 세 공간 템플릿은 `scripts/create-space-templates.mjs`에서 생성한다. 재생성은 프론트엔드 workspace의 `pnpm assets`로 수행한다.
