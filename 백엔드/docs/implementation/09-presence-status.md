# 접속 상태와 방해 금지

T16.1의 접속별 상태 선택을 추가했다. 참가자 패널에서 `온라인`, `자리 비움`, `방해 금지`를 직접 선택할 수 있고, 월드 서버가 상태를 승인해 10Hz 스냅샷과 참가자 목록에 반영한다. 상태는 현재 접속에만 적용되며 새 플레이어 접속은 온라인으로 시작한다.

## 정책

- `AVAILABLE`은 근거리/PRIVATE 구역 미디어와 찌르기를 허용한다.
- `AWAY`와 `DND`는 기존 근거리 미디어 연결과 로컬 캡처 트랙을 정리하고 새 미디어 요청과 찌르기를 서버에서 거부한다. 발신자 자신이 두 상태 중 하나일 때도 찌르기를 보낼 수 없다.
- 두 상태에서도 공간/구역 범위의 채팅은 계속 수신한다. DND 상태는 참가자에게 보이고, 앱 내 읽지 않음 표시는 계속 동작한다.
- 상태 전환은 월드 actor에서 처리하고 접속 epoch와 750ms 전환 제한을 검증한다. 전환 시 미디어 epoch를 올리고 SFU revoke와 최신 정책 frame을 사용해 예전 송출·구독 연결을 제거한다. 미디어 요청 경로도 상태를 다시 검증한다.
- 기본 활성화된 자동 자리 비움은 포인터/키보드/터치/스크롤 입력과 탭 복귀를 활동으로 본다. 5분 동안 입력이 없으면 현재 상태가 `AVAILABLE`일 때만 `AWAY`로 전환한다. 자동 전환으로 만든 `AWAY`만 입력이 돌아오면 `AVAILABLE`로 복구하며, 사용자가 직접 설정한 `AWAY`/`DND`는 자동으로 덮어쓰지 않는다. 설정은 브라우저별로 저장하고 사용자가 끌 수 있다.
- 상태는 같은 공간의 참가자에게 공개되지만 계정에 저장하거나 다른 공간에 전달하지 않는다.

## 현재 범위

접속 중 DND인 계정은 DM Web Push를 받지 않는다. 각 월드는 현재 DND 플레이어의 계정·플레이어 ID만 Redis sorted set에 기록하고 2초마다 만료 점수와 30초 키 만료를 갱신한다. 상태 해제·접속 종료 때 해당 플레이어 항목을 제거한다. API 발송 작업자는 현재 시각 이후에도 유효한 표식이 있는지 발송 직전에 확인한다. Redis 확인이 실패하면 푸시를 발송하지 않고 outbox 재시도로 넘긴다. 만료 점수로 멈춘 월드의 표식이 살아 있는 상태처럼 보이지 않게 한다.

계정 간 상태 동기화, 관리자 강제 상태, 전체 공간을 아우르는 상태 설정은 후속 범위다. Playwright 가상 시계로 5분 유휴를 진행시켜 브라우저에서 실제 preview World WebSocket 상태가 `AVAILABLE`→`AWAY`로 바뀌고 복귀 입력 후 `AVAILABLE`로 돌아오는 것을 확인했다. 이 검사는 5분의 실제 벽시계 대기를 사용하지 않는다.

## 코드 위치

- 계약: `contracts/world.schema.json`, `scripts/generate-contracts.mjs`
- 서버 상태/미디어·찌르기 정책: `apps/world/src/main/java/town/hufs/world/WorldHandler.java`
- 클라이언트 요청·승인: 프론트 workspace의 `src/game/WorldConnection.ts`
- 선택 UI·상태 표기: 프론트 workspace의 `src/app/App.tsx`, `src/app/styles.css`

후속 구현(2026-09-22): 사람들 패널에 기본 활성화된 자동 자리 비움 설정을 추가했다. 5분 동안 포인터·키보드·터치·스크롤 활동이 없을 때 `AVAILABLE`만 `AWAY`로 바꾸고, 다시 활동하면 자동으로 전환한 경우에만 `AVAILABLE`로 돌아온다. 직접 선택한 `AWAY`와 `DND`는 유지하며 설정은 브라우저별로 저장한다.

통합 검증(2026-09-25): Docker Testcontainers에서 두 계정의 패키지 월드 접속으로 DND 전 상태의 SFU 송출 허용을 확인한 뒤, DND 전환이 기존 SFU 연결 revoke, 새 미디어 요청 거부, 합류 요청·찌르기 거부로 이어지는 것을 확인했다. DND 중 공간 채팅은 상대에게 전달되고 Redis 푸시 억제 표식이 생기며, AVAILABLE 복귀 시 표식이 제거된다. AWAY에서도 미디어 요청이 거부된다. 차단 변경은 별도 두 패키지 월드 검사에서 기존 세션 즉시 갱신, 합류·찌르기 차단, 상대 차단 시 채팅 제외까지 통과했다. 자동 5분 자리 비움 브라우저 왕복과 실제 HUFS SSO 계정의 다중 월드 검수는 남아 있다.

자동 자리 비움 회귀(2026-09-25): `tests/e2e/auto-away.spec.ts`에서 Playwright 가상 시계로 5분 무활동 임계치를 지나 실제 preview 월드 상태의 `AVAILABLE`→`AWAY` 전환과 포인터 복귀 뒤 `AVAILABLE` 복원을 확인했다. 첫 실행이 전환 직후 800ms 보호 구간 안의 활동을 놓치는 버그를 재현했다. 이제 활동이 먼저 들어와도 보호 구간의 남은 시간만큼 복귀를 예약한다. 같은 브라우저 검사에서 사용자가 직접 고른 `AWAY`가 활동으로 바뀌지 않는 것도 확인했다. 자동 복귀 정책 Vitest와 Docker-backed Playwright 1/1 통과.
