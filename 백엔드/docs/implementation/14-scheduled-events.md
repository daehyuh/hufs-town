# 공간별 예정 행사

공간 운영자가 날짜가 있는 행사를 등록·수정·취소하고, 공간을 볼 수 있는 참가자가 일정과 참가 안내를 확인한다. 일정 카드의 **공간 입장**은 공간의 기존 입장·승인 흐름을 다시 사용한다.

## 저장 및 권한

Flyway V30은 `town_scheduled_event`에 이름, 설명, 참가 안내, HTTPS 자료 링크, 시작·종료 시각, 만든 계정, 취소 시각을 저장한다. V32의 `town_scheduled_event_rsvp`는 계정별 참석 의사를 저장하고 행사나 계정 삭제 때 함께 지운다. 공간 삭제 때 예약도 함께 삭제된다. 운영자는 공간당 예정 행사 50개까지 둘 수 있고 계정은 하루 10개까지 생성할 수 있다. 예정 시작은 1분 이후부터 365일 안이며 종료 시각은 시작보다 1분~12시간 뒤로 제한한다.

`GET /api/v1/spaces/{spaceId}/scheduled-events`는 공개·링크 공개 공간과 멤버인 비공개 공간에서 호출할 수 있다. 영구 차단된 계정은 일정을 읽을 수 없다. 목록에는 예정 행사와 최근 30일간 취소된 일정만 포함한다. `POST`, `PATCH`, `DELETE`는 OWNER/ADMIN만 사용할 수 있다. 취소는 행을 지우지 않고 취소 상태를 저장해 참가자에게 알린다. 일정 이름·설명·참가 안내·링크·시간은 서버에서 다시 검증한다.

공간을 읽을 수 있는 활성 계정은 `PUT /api/v1/spaces/{spaceId}/scheduled-events/{eventId}/rsvp`에 `GOING`, `INTERESTED`, `DECLINED` 중 하나를 보내 참석 의사를 등록하거나 바꿀 수 있다. 목록과 응답에는 세 응답의 합계와 현재 계정의 응답만 노출하고 다른 참가자의 신원은 공개하지 않는다. 이 응답은 좌석 예약이나 입장 권한을 부여하지 않는다. 행사가 시작되거나 취소되면 응답 변경은 닫히지만, `DELETE .../{eventId}/rsvp`로 본인 응답을 철회할 수 있다. 일정 관리와 RSVP 모두 Redis 요청 제한을 공유한다.

## 화면

공간 로비 카드의 일정 버튼에서 행사 목록을 연다. 운영자는 새 일정 등록, 수정, 취소를 할 수 있고 일반 참가자는 날짜, 설명, 참가 안내, 자료 링크를 보고 공간에 입장할 수 있다. 열린 일정 창은 30초 간격으로 갱신되며 직접 새로고침도 제공한다.

일정 목록 창에서 참가자는 세 응답 중 하나를 선택하고 집계와 본인 응답을 확인·철회할 수 있다. 이메일·푸시 알림, 외부 캘린더 동기화, 취소 전 참가자에게 별도 승인 절차는 구현하지 않았다.
