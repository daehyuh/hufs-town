# 07. Gather·ZEP 기반 화면과 사용 흐름

반영일: 2026-09-21. 사용자 추가 방향: **실제 ZEP과 Gather를 적극적으로 레퍼런스로 삼는다.**

## 1. 기준

플레이·대화 경험은 **Gather Classic(1.0)**, 공간·맵 관리 경험은 **ZEP**을 주 레퍼런스로 삼는다. 이 문서는 공식 가이드의 설명과 브라우저에서 확인한 예시 화면에 근거한다. 두 제품의 로그인 후 기능 전체를 직접 사용해 검증한 기록은 아니다.

같은 위치에서 익숙한 기능을 찾을 수 있도록 화면 구성·버튼 역할·상태 전환을 참고하고, 월드 그래픽과 브랜드는 제공된 도트 세트·GDG HUFS 에셋으로 구현한다. 기능별 주 레퍼런스를 정해 화면마다 조작 체계가 바뀌지 않게 한다.

## 4. 플레이 화면의 구체적 배치

데스크톱 1440×900 시안 기준이다. 브라우저 크기가 달라지면 영역이 유동적으로 줄어든다.

- **상단 정보:** 공간명·현재 맵·접속 상태·보기 전환. 독립 회의실에서는 구역명과 잠금 상태를 함께 표시한다.
- **상단 통화 스트립:** 높이 약 104~128px의 영상 카드. 현재 연결된 사람만 표시하고 발화자/사용자 고정 선택을 우선한다.
- **좌측 기능 레일:** 약 56px. 사람·채팅·지도·행사·편집 진입을 일관된 순서로 제공한다.
- **중앙:** 도트 맵. 이름표, 말풍선, 이모지, 상호작용 안내가 아바타와 연결된다.
- **우측 패널:** 약 320px. 채팅·참가자·행사 중 선택한 하나를 표시하며 접을 수 있다.
- **하단 조작부:** 마이크·카메라·화면공유·감정표현·손들기·나가기. 장치 선택은 각 장치 버튼 옆 메뉴로 연다.
- **통화 범위 표시:** 하단 조작부 위에 `주변 4명`, `스터디룸 A · 6명`, `행사 전체`를 항상 명시한다.

회의 보기에서는 영상/공유 화면이 중앙 영역을 차지하고 지도는 축소하거나 숨긴다. 지도를 숨겨도 사용자의 위치와 통화 영역은 바뀌지 않는다. 화면을 확대하는 동작이 전체 송출을 의미하지 않게 한다.

## 5. 에디터의 구체적 배치

상단은 `선택 / 바닥 / 오브젝트 / 충돌 / 구역 / 포털 / 실행 취소 / 재실행`, 우측 끝은 `초안 저장 / 미리보기 / 게시`로 구성한다. 좌측은 맵 목록과 레이어, 우측은 선택한 에셋 또는 구역의 설정이다.

오브젝트 도구를 선택하면 우측 카탈로그에서 검색·태그·즐겨찾기를 보여준다. 지도에서 배치한 오브젝트를 선택하면 같은 패널을 속성 편집으로 전환한다. 구역 편집에서는 통화 경계·정원·출입 규칙을 보이게 하고 일반 플레이 화면에는 자연스러운 바닥/간판/문으로 표현한다.

ZEP의 맵 목록에서 관리하는 흐름을 참고하되, 기존 설계의 초안·게시 분리와 안전한 버전 전환을 적용한다. 게시 전에는 바뀐 맵과 현재 접속자에게 미치는 영향을 안내한다.

## 6. 그래픽 적용

지도 안 캐릭터·나무·길·가구는 RPG 도트 세트를 중심으로 선택한다. 통화 카드와 조작부는 모던 웹 UI로 만들고, GDG 파랑을 선택/포커스 색으로 사용한다. 월드 조작부는 어두운 중립색, 편집·설정 패널은 밝은 표면을 기본 시안으로 제안한다.

GDG 로고는 공간 헤더·광장 간판·행사 무대, 캠퍼스 일러스트는 로그인·공간 표지·포스터에 사용한다. 서비스 이름과 화면 문구는 HUFS Town에 맞춰 작성한다.

## 7. 구현 순서에 반영

기존 T08(공간 UI), T12~T14(통화), T18~T20(에디터), T21(템플릿), T22(행사)를 시작할 때 이 문서의 해당 REF ID를 함께 읽는다.

첫 UI 제작은 다음 네 화면을 기준으로 한다.

1. 지도 + 대화 영상 + 채팅 패널이 보이는 플레이 화면.
2. 아바타 선택과 장치 테스트가 있는 입장 준비 화면.
3. 화면공유를 확대하고 참가자를 고정할 수 있는 회의 화면.
4. 맵 목록·에셋 카탈로그·속성·미리보기·게시가 있는 에디터.

각 화면은 레퍼런스가 설명하는 핵심 동작이 가능한지 확인한 뒤 GDG 브랜딩과 세부 표현을 다듬는다. 정적 화면만 비슷하게 만든 상태를 기능 구현 완료로 처리하지 않는다.

## 8. 사용성 확인 기준

- Gather/ZEP을 써 본 참가자가 설명 없이 마이크·카메라·공유·채팅을 찾는다.
- 가까이 가기/멀어지기/회의실 입장 시 누구와 연결됐는지 알 수 있다.
- 지도→회의→공유 확대 전환 후 같은 대화로 돌아올 수 있다.
- 운영자가 에셋 하나를 찾아 배치하고 미리보기·게시까지 진행할 수 있다.
- 화면에 보이는 영상 선택과 실제 통화 접근 범위를 혼동하지 않는다.
- 1280×720에서도 주요 조작과 현재 통화 범위가 잘리지 않는다.
